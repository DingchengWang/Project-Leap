Install analysis modules

Open Modules & Maintenance in Project Leap and choose the modules you need. The application downloads each module together with its required components, including the analysis runtime, models, and Fiji where needed.

The installation guide covers first launch and module setup. For changes between releases, see the fluorescence module changelog and cell counting releases.

Earlier standalone script package

Project Leap 2D v1.0.1 remains available for the earlier fluorescence-analysis workflow. It runs through its own installation, analysis, and repair scripts. Choose this package if you need that standalone workflow; use the desktop download above for the current application.
