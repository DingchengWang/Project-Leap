Author and research affiliation

Dingcheng Wang developed Project Leap as a neuroscience undergraduate at The Ohio State University, with research affiliation to the Min Zhou Laboratory, Department of Neuroscience, College of Medicine.

AI tools assisted with code implementation, debugging, packaging, and documentation. Dingcheng Wang directed the research requirements, analysis rules, biological interpretation, and development decisions, and was responsible for acceptance review.

Methods and tools

Project Leap uses the following upstream tools for distinct parts of the analysis:

  • Cellpose-SAM provides segmentation for the eGFP fluorescence-analysis route and the counting module.
  • InstanSeg fluorescence model supplies DAPI nuclear candidates in the mature GFAP-only fluorescence-analysis route. Project Leap uses these candidates with GFAP structure to define the cell regions.
  • Fiji supports interactive review of fluorescence regions and measures the raw target-channel projections within the final regions.

Source and licenses

The source is maintained in three repositories:

  • Project Leap: desktop application and shared platform.
  • Astrocyte fluorescence module: fluorescence analysis engine and guide.
  • Cell Counting module: counting engine and guide.
