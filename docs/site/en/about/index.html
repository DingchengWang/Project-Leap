Author and research

Project Leap was developed by Dingcheng Wang, an undergraduate neuroscience student at The Ohio State University. The research projects it primarily supports are based in the Min Zhou Laboratory, Department of Neuroscience, College of Medicine, at The Ohio State University.

The software’s research requirements, biological interpretations, internal analysis methods, and cell parameters are all original. GPT-5.6 Sol / GPT-6 Astra assisted with code implementation, debugging, packaging, and documentation during development.

Open-source tools used in the software

The following are upstream analysis tools that perform different tasks:

  • Cellpose-SAM: provides the base segmentation for fluorescence analysis with eGFP and for the cell counting module.
  • InstanSeg fluorescence model: generates candidate DAPI nuclear regions for GFAP-only fluorescence analysis of mature samples. Project Leap then combines these candidates with GFAP structural patterns to define cell regions.
  • Fiji: used to interactively review fluorescence analysis regions and measure the intensity of the raw target-channel projection within the final regions.

Source code and licensing

The source code is maintained in three repositories:

  • Project Leap: the desktop application and shared platform.
  • Astrocyte fluorescence module: the fluorescence analysis engine and guide.
  • Cell counting module: the counting engine and guide.
