星形胶质细胞荧光分析与细胞计数

Project Leap 是一款面向多通道荧光图像的 Mac 分析软件。它将自动分析与人工审核结合，研究者可以对照图像调整测量区域，并确认哪些细胞计入总数。

Project Leap

按研究任务选择模块

01

星形胶质细胞荧光强度分析

荧光模块测量审核后的整细胞、胞体和突起区域内的目标荧光，并保留测量值与细胞及最终边界的对应关系。

了解荧光分析 →

02

细胞计数

计数模块结合 DAPI 与另一荧光通道识别候选细胞。研究者可沿 Z 轴逐层核对细胞，确认哪些细胞纳入星形胶质细胞总数。

了解细胞计数 →

图像在本机分析，结果按任务保存

每次保存的分析都可在“任务与结果”中查看，包括测量表、标注图及对应的区域或审核会话。计数会话还可重新打开，继续编辑。原始 TIFF 保留在原文件夹。
