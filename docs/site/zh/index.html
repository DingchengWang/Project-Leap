本地荧光图像分析

Project Leap 将星形胶质细胞荧光强度分析和细胞计数整合到一款面向 Apple Silicon Mac 的桌面软件中。导入 TIFF 图像，审核候选区域或细胞，并将结果与分析记录一同保存。

使用 PROJECT LEAP

将分析与人工审核连接起来。

主程序统一管理模块、分析任务和已保存的结果。图像在你的 Mac 上完成分析，原始 TIFF 保留在原位置。

  1. 选择图像并指定通道。导入受支持的 TIFF；图像包含多个图像组或时间点时，选定本次分析对象，再设置通道角色。
  2. 审核候选结果。在 Fiji 中编辑荧光分析区域，或在内置计数工作台核对细胞及其 Z 位置。
  3. 保存并查看已有工作。在“任务与结果”中查看分析记录和输出文件。已保存的计数会话可以重新打开并继续编辑。
