作者与研究归属

Project Leap 由 Dingcheng Wang 开发。作者为俄亥俄州立大学神经科学本科生，研究隶属于医学院神经科学系 Min Zhou 实验室。

开发过程中，AI 工具辅助代码实现、调试、打包和文档编写。Dingcheng Wang 主导研究需求、分析规则、生物学解释和开发取舍，并负责验收审核。

分析中使用的方法与工具

以下上游工具承担不同的分析任务：

  • Cellpose-SAM：为含 eGFP 的荧光分析分支及计数模块提供分割结果。
  • InstanSeg fluorescence model：在成熟样本的 GFAP-only 荧光分析分支中生成 DAPI 细胞核候选。Project Leap 再结合这些候选和 GFAP 结构确定细胞区域。
  • Fiji：用于交互式审核荧光分析区域，并在最终区域内测量原始目标通道投影的强度。

源码与许可

源码分别保存在三个仓库中：

  • Project Leap：桌面主程序及共享平台。
  • 星形胶质细胞荧光模块：荧光分析引擎与指南。
  • 细胞计数模块：计数引擎与指南。
