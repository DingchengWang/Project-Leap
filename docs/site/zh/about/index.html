English · 项目首页 · 使用指南

Project Leap 是用于免疫组织化学图像分析的本地科研平台。桌面主程序提供星形胶质细胞荧光强度分析和细胞计数两个模块。平台管理安装、图像导入、任务记录、结果和维护，各模块提供自己的分析流程和审核工具。

作者与研究归属

Project Leap 由 Dingcheng Wang 开发，作者为俄亥俄州立大学神经科学本科生，研究隶属于医学院神经科学系 Min Zhou 实验室。软件“关于”页面记录了上述归属，项目 NOTICE 保留作者署名。

开发方式与科学责任

AI 工具辅助完成代码实现、调试、打包和文档编写。Dingcheng Wang 主导研究需求、生物学解释、分析规则、取舍及验收审核。

使用 Project Leap 的研究者需要判断分析是否适合自己的实验，审核软件提出的感兴趣区域或细胞身份，并解释保存的测量结果。各模块指南分别说明输入要求、审核步骤和科学适用范围。

开源代码与第三方组件

Project Leap 原创代码采用 Apache License 2.0，署名见 NOTICE。第三方软件和模型保留各自的许可证与版权声明。THIRD_PARTY_NOTICES.md 提供保留的许可材料和上游来源链接。

源码分为三个仓库：

  • Project Leap：桌面主程序及共享平台。
  • 星形胶质细胞荧光模块：荧光分析引擎与指南。
  • 细胞计数模块：计数引擎与指南。
