作者与研究

Project Leap 由俄亥俄州立大学神经科学本科生Dingcheng Wang开发。主要服务的研究项目隶属于俄亥俄州立大学医学院神经科学系 Min Zhou 实验室。

该软件的研究需求、生物学解释、内部分析逻辑和细胞参数均为原创。开发过程中使用了GPT-5.6 Sol / GPT-6 Astra辅助代码实现、调试、打包和文档编写。

软件使用的开源工具

以下为上游分析工具承担不同的分析任务：

  • Cellpose-SAM：为含 eGFP 的荧光分析及计数模块提供基础分割。
  • InstanSeg fluorescence model：在成熟样本的 GFAP-only 荧光分析中生成 DAPI 细胞核候选区域。Project Leap软件随后再结合这些候选和 GFAP 结构模式确定细胞区域。
  • Fiji：用于交互式审核荧光分析区域，并在最终区域内测量原始目标通道投影的强度。

源码与许可

源码分别保存在三个仓库中：

  • Project Leap：桌面主程序及共享平台。
  • 星形胶质细胞荧光模块：荧光分析引擎与指南。
  • 细胞计数模块：计数引擎与指南。
