# 使用指南

[English](user-guide.en.md) · [项目首页](../README_中文.md) · [关于](about.zh.md)

**当前版本：Project Leap v1.0.0。** 安装主程序后，选择需要的分析模块，再按模块指南准备图像、运行分析并审核结果。本指南说明安装、历史分析管理和软件设置。

## 1. 安装主程序

需要运行 **macOS 27 或更高版本的 Apple Silicon Mac**。下载主程序、安装模块和获取更新时需要联网。

1. 打开[项目官网](https://dingchengwang.github.io/Project-Leap/zh/)或 [GitHub Releases](https://github.com/DingchengWang/Project-Leap/releases)。
2. 下载 [`Project-Leap-1.0.0-macOS-arm64.dmg`](https://github.com/DingchengWang/Project-Leap/releases/download/v1.0.0/Project-Leap-1.0.0-macOS-arm64.dmg)。
3. 打开 DMG，将 **Project Leap.app** 拖入**应用程序（Applications）**文件夹。
4. 从“应用程序”打开 Project Leap。复制完成后即可推出 DMG。

公开 DMG 包含主程序本体。分析模块及其依赖通过 Project Leap 安装。

### macOS 阻止首次启动时

系统可能提示无法验证开发者，或 Apple 无法检查应用是否包含恶意软件。

如果你从项目发布页面下载了应用，并决定继续打开：

1. 先尝试打开一次 **Project Leap.app**，然后关闭提示。
2. 进入**系统设置 → 隐私与安全性**，向下找到阻止此应用的提示。
3. 点击**仍要打开**，在下一条提示中确认**打开**；如果系统要求身份验证，按提示完成。

macOS 会保存该应用的例外设置。上述步骤依据 [Apple 对未公证应用的官方说明](https://support.apple.com/zh-cn/102445)。如果提示应用**将损坏你的计算机**或**已损坏**，应另行排查。受组织管理的 Mac 若不允许设置例外，需要联系管理员。

## 2. 安装分析模块

1. 在侧边栏选择**功能与维护**。
2. 找到需要的模块，点击**安装分析模块**。
3. 保持软件打开，等待下载、校验和安装完成。
4. 模块状态显示**已安装**、安装按钮显示**模块已就绪**后，即可使用。

可以安装一个模块，也可以同时安装两个。Project Leap 会一并安装所需依赖，其中荧光模块使用 Fiji 审核感兴趣区域。

分析或审核进程正在使用组件时，软件暂停安装和修复。完成相关操作后再维护模块。

## 3. 选择模块并开始分析

在侧边栏选择已安装模块，进入其**分析工作台**。按对应指南完成图像选择、通道指定、分析、审核和保存：

| 模块 | 用途 | 指南 |
|---|---|---|
| **星形胶质细胞荧光强度分析** | 在星形胶质细胞感兴趣区域内测量荧光强度，并在 Fiji 中审核区域。 | [荧光模块使用指南](https://github.com/DingchengWang/Project-Leap-2D-Integrated-IHC-fluorescence-analysis/blob/main/docs/guide.zh.md) |
| **细胞计数** | 审核 DAPI 和辅助通道提供的候选细胞，编辑计数并保存确认结果。 | [细胞计数使用指南](https://github.com/DingchengWang/Project-Leap-Cell-Counting/blob/main/docs/guide.zh.md) |

分析期间，**运行细节**显示进度和提示。你可以切换查看其他页面或模块，待当前分析结束后再启动下一项分析。

完成人工审核后，通过模块内的控件保存结果。细胞计数会把编辑内容保存为草稿，供之后继续审核；点击**确认并保存 Astrocyte 计数**后，软件才保存确认结果。确认后的新修改仍属于草稿，需要再次确认才能保存为新的结果版本。

## 4. 查看和管理历史分析

打开**任务与结果**。任务按模块分组，点击一条记录即可展开**任务详情**，查看状态、结果预览和输出文件。

- 点击预览或文件名可打开相应文件。已完成任务的**打开结果文件夹**可定位其输出目录。
- 展开**运行细节**可查看已保存的软件、输入、参数、审核和耗时记录，具体内容取决于该任务保存了哪些信息。
- 计数任务可通过**重新打开计数**编辑已保存的计数，或通过**继续审核计数**恢复已有审核会话。保存修改的方法见计数模块指南。
- 点击**刷新占用**，更新各分析在软件内部占用磁盘空间的估计值。

删除单项分析可点击该行的垃圾桶按钮；批量删除时，点击**多选**，勾选记录后点击**删除所选**。确认前请核对范围：这会永久删除所选分析在软件内部保存的数据，原始图像和已导出到软件数据目录之外的文件会保留。选择**一个月内不再询问**后，软件会暂停显示删除确认，并在一个日历月后恢复询问。

重新分析和查看原始 Z 层需要原始图像，请保留这些文件。计数会话提示原图已移动时，可使用会话内的重新定位入口，由软件核对新路径的图像是否与该任务匹配。

## 5. 调整设置

### 语言与外观

进入**设置 → 语言与外观**。**界面语言**可选 **English** 或**中文**；**外观**可选**跟随系统**、**浅色**或**深色**。Fiji 和浏览器打开的页面使用各自的外观设置。

### 存储与迁移

**设置 → 存储与数据**显示当前软件数据目录。点击**打开软件数据**可在 Finder 中打开它。该目录包含已安装组件、任务记录、审核数据和保存的结果。

需要迁移时，先完成正在进行的工作，点击**更改存储目录**，选择一个**新的空文件夹**。等待软件迁移、校验数据并完成重启。请通过此入口更改受管理数据的位置；在 Finder 中直接移动文件夹会使软件仍指向原来的路径。

原始输入图像仍保存在原位置。迁移软件数据不会移动这些图像或外部导出文件。如果软件提示已配置的数据目录不存在，请先重新连接对应磁盘或恢复该目录，再打开软件。

### 清理缓存

在**存储与数据**中点击**清理缓存**并确认，可删除能重新生成的界面缓存和已不再使用的临时文件。原始图像、分析结果和审核数据会保留。若要删除某次分析及其已保存数据，应使用任务删除功能。

### 更新软件

进入**设置 → 软件更新 → 检查更新**，统一检查主程序和已安装模块。按更新提示操作；组件下载并校验后才会启用，主程序更新会重新启动软件。更新所需的组件仍在使用时，会等待相关工作结束。

### 检查并修复模块

在**功能与维护**中，点击已安装模块的**检查并修复**。软件会检查组件内容，并以**当前已安装的同一版本**修复缺失或损坏的组件。完整校验通过时，会提示无需修复。需要升级到可用的新版本时，使用**检查更新**。

### 删除模块或卸载软件

**功能与维护**中的**删除模块**会移除该模块的运行组件，保留历史任务和结果。其他已安装模块仍在使用的共享组件会保留；没有模块再需要共享模型或 Fiji 时，软件可能询问是否同时移除它们。

**设置 → 卸载软件**提供两种方式：一种保留任务、最终感兴趣区域、正式结果和必要恢复数据；另一种同时永久删除软件数据目录。两种方式均不影响该目录之外的原始输入。按需要保留的数据选择卸载方式。

## 6. 操作中断时如何处理

| 遇到的情况 | 下一步 |
|---|---|
| 模块下载或安装失败 | 查看**功能与维护**中的提示；需要时恢复网络后重试。已安装模块显示**需要修复**时，点击**检查并修复**。 |
| 组件校验失败 | 通过软件重试；再次失败时，将完整提示和模块版本报告到 [GitHub Issues](https://github.com/DingchengWang/Project-Leap/issues)。 |
| 维护按钮不可用 | 完成当前占用组件的分析、审核或更新，再重试。 |
| 分析失败或中断 | 在**任务与结果**中查看该任务的提示和**运行细节**，按模块指南处理对应步骤；提示明确指向组件问题时再修复模块。 |
| 结果预览无法载入 | 点击预览打开原输出文件，或使用**打开结果文件夹**。 |
| 找不到原图或软件数据目录 | 恢复原位置或重新连接磁盘；移动后的计数原图可通过会话内入口重新定位。 |

报告问题时，请提供 Project Leap 版本、模块版本、macOS 版本、失败操作和完整提示。只有在有权分享图像数据时才附上图像。
