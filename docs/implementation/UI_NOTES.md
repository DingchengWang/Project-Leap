# Project Leap 界面行为

分析工作台分别保存计数与星形胶质细胞荧光强度分析的输入、运行状态和审核会话。导航固定先显示荧光，再显示计数及后续模块。导航切换保留状态；运行任务参数锁定，全局同时只能执行一个科学任务。

计数左侧为图像导入、分析通道、显示通道与颜色三张卡；右侧为状态、四步流程和本地模块说明。DAPI 支持自动识别和手动选择。辅助通道与 DAPI 不同，标记物支持 eGFP、Biocytin、ALDH1L1 和自定义。运行前预选审核显示通道；进入审核后可查看本次设置，参数只读。

界面固定显示 Astrocyte / High Likelihood / Unrecognized / Neurons 四项。Astrocyte 为绿色编号圈；High Likelihood 为琥珀菱形；Unrecognized 为黄色轻点；Neurons 为紫色小方形且不计数。顶部左侧显示 `Total Astrocyte: N`，右侧按以上顺序横向排列各自数量。High Likelihood 只显示高可能性待审核对象，Unrecognized 只显示其余待审核对象，两项不重叠。总数只计未删除的 Astrocyte；只有 High Likelihood 普通点击直接加入，Unrecognized 和 Neurons 需选择后使用“加入计数”，未处理完也可保存。Command 仅多选，批量可用“加入计数”；手工删除隐藏对象并保留原 status，不自动变成 Neurons，支持撤销/重做。

当前计数对象连续编号为 1…N，MIP、各 Z 层、PNG 和 CSV 中保持一致，内部 `cell_id` 不因编号变化而改变。编号旁不显示引导线。PNG 使用独立于审核界面、随输出分辨率成比例调整的较大字号。

确认保存成功后，计数工作台恢复为新图像输入状态；已保存结果从“任务与结果”重开。保存失败时继续保留审核会话。

“高Astrocyte可能性”只展示引擎明确提供的 `review_hint=likely_astrocyte`，不由界面猜测。切片仍使用双 Image 缓冲：候选像素就绪且请求身份匹配时，画面、层号和标记同步切换；此前保持完整旧帧。历史 schema 1 结果明确标记其来源。

侧边栏与横向年龄选择器采用原生 AppKit 玻璃选择组；Controller 决定最终选中值。年龄自动对应 null，新图像恢复自动，GFAP-only 禁用 Neonatal。中文模块全名为“星形胶质细胞荧光强度分析”，英文为“Astrocyte Fluorescence Intensity Measurement”。

本地说明按钮直接打开随应用交付的双语 HTML，无需网络。

拖动 Z 滑块时，大图自动使用显示代理，默认最长边 1536，按原图像素中心最近邻采样；停稳约 180 ms 后请求原分辨率，放大也恢复原生显示。界面不显示预览徽章或预览设置项。代理图像仅用于显示，不改变原图 XYZ 标记、科学标签、计数或导出；临时切片 PNG 使用无损压缩级别 1。


审核对象为全局细胞身份：DAPI 核来源、独立辅助通道胞体来源和已配对来源均以一个细胞显示。编号和逐层位置保留实际观察来源，核与胞体标签分别保存；正常手动添加、加入计数、删除、合并、撤销/重做继续可用。
