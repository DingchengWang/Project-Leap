# Project Leap 界面行为

## 工作台与导航

星形胶质细胞荧光强度分析和细胞计数工作台分别保存自己的输入、运行状态和审核会话。侧边栏先显示荧光，再显示计数及后续模块。切换页面保留工作台状态；任务运行期间参数锁定，全局同时只能执行一个科学任务。

侧边栏和横向年龄选择器使用原生 AppKit 玻璃选择组，由 Controller 确定最终选中值。年龄“自动”对应 `null`，新图像恢复为自动；GFAP-only 禁用 Neonatal。荧光模块的中文全名为“星形胶质细胞荧光强度分析”，英文为“Astrocyte Fluorescence Intensity Measurement”。

计数工作台左侧依次显示图像导入、分析通道、显示通道与颜色三张卡；右侧显示状态、四步流程和模块说明入口。DAPI 可以自动识别或手动选择。辅助通道必须与 DAPI 不同，标记物可选 eGFP、Biocytin、ALDH1L1 或自定义。用户在运行前选择审核显示通道，进入审核后可以查看这些设置，参数保持只读。

## 计数审核与保存

审核以全局细胞身份为对象：DAPI 核来源、独立辅助通道胞体来源和已配对来源均以一个细胞显示。编号与逐层位置保留实际观察来源，核和胞体标签分别保存。编辑器支持手动添加、加入计数、删除、合并，以及撤销和重做。

界面按以下顺序显示四类对象和各自数量：

| 类别 | 显示与操作 |
|---|---|
| Astrocyte | 绿色编号圈，未删除对象计入总数。 |
| High Likelihood | 琥珀菱形，普通点击直接加入计数。 |
| Unrecognized | 黄色轻点，选择后使用“加入计数”。 |
| Neurons | 紫色小方形，默认不计数；选择后可用“加入计数”修正。 |

High Likelihood 只包含引擎明确标记 `review_hint=likely_astrocyte` 的待审核对象，Unrecognized 包含其余待审核对象，两类互不重叠。“高Astrocyte可能性”提示由引擎提供，界面不自行推断。

顶部左侧显示 `Total Astrocyte: N`，右侧横向排列四类数量。Command 点击只多选对象，随后可批量“加入计数”。手工删除会隐藏对象并保留原 `status`，不会将其归入 Neurons；撤销可以恢复。

当前计数对象连续编号为 1…N，MIP、各 Z 层、PNG 和 CSV 中保持一致，内部 `cell_id` 不随编号变化。编号旁没有引导线。PNG 使用独立于审核界面的字号，并按输出分辨率等比例调整。

用户可以在 High Likelihood 或 Unrecognized 尚有对象时确认保存。保存成功后，工作台恢复到新图像输入状态，已保存结果可从“任务与结果”重开；保存失败时继续保留审核会话。既有 schema 1 结果明确标记其来源。

## Z 层显示

切片使用两个 Image 缓冲。候选像素就绪且请求身份匹配后，画面、层号和标记同步切换；此前保留完整旧帧。

拖动 Z 滑块时，若原图最长边大于 1536 且 `viewZoom <= 1`，显示代理将最长边限制为 1536，按原图像素中心最近邻采样。拖动结束后优先复用匹配的原生缓存，否则约 180 ms 后请求原分辨率；放大至 `viewZoom > 1` 时也恢复原生显示。界面不显示预览徽章或预览设置项。代理只用于显示，原图 XYZ 标记、科学标签、计数和导出保持原数据；临时切片 PNG 使用无损压缩级别 1。
