## Install analysis modules

Open **Modules &amp; Maintenance** in Project Leap and choose the modules you need. The application downloads each module together with its required components, including the analysis runtime, models, and Fiji where needed.

| Module | Current version | Installation |
| --- | --- | --- |
| Astrocyte fluorescence intensity measurement | v1.1.1 | In Project Leap |
| Cell counting | v1.0.0 | In Project Leap |

The [installation guide](../guide/) covers first launch and module setup. For changes between releases, see the [fluorescence module changelog](https://github.com/DingchengWang/Project-Leap-2D-Integrated-IHC-fluorescence-analysis/blob/main/CHANGELOG.md) and [cell counting releases](https://github.com/DingchengWang/Project-Leap-Cell-Counting/releases).
