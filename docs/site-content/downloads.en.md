## Modules for the desktop application

Install the modules you need from **Modules &amp; Maintenance** in Project Leap. The application will download each module and its required components. You do not need to unpack module archives manually.

| Module | Version | Availability |
| --- | --- | --- |
| Astrocyte fluorescence intensity measurement | 1.1.1 | Install in Project Leap |
| Cell counting | 1.0.0 | Install in Project Leap |

Fluorescence module 1.1.1 fixes compatibility with the shared scientific runtime. Version 1.1.0 introduced the desktop workflow, automatic channel preparation, and final region archive; the scientific rules remain at version 1.0.1.

[Read the installation guide](../guide/) for the application requirements and installation steps.
