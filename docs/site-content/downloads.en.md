## Install analysis modules

Open **Modules & Maintenance** in Project Leap and select the modules you need. The app downloads each module together with its dependencies, including the analysis runtime, models, and Fiji when needed.

| Module | Current version | Installation |
| --- | --- | --- |
| Astrocyte Fluorescence Intensity Measurement | v1.1.1 | Install within Project Leap |
| Cell Counting | v1.0.0 | Install within Project Leap |

See the [installation guide](../guide/) for first launch and module setup. For changes in each version, see the [fluorescence module changelog](https://github.com/DingchengWang/Project-Leap-2D-Integrated-IHC-fluorescence-analysis/blob/main/CHANGELOG.md) and [cell counting release history](https://github.com/DingchengWang/Project-Leap-Cell-Counting/releases).
