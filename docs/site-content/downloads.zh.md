## 桌面软件的分析模块

在 Project Leap 的“功能与维护”中安装所需模块。主程序会下载模块及其依赖组件，无需手动解压模块归档。

| 模块 | 版本 | 可用状态 |
| --- | --- | --- |
| 星形胶质细胞荧光强度分析 | 1.1.1 | 通过 Project Leap 安装 |
| 细胞计数 | 1.0.0 | 通过 Project Leap 安装 |

荧光模块 1.1.1 修复了与共享科学运行环境的兼容问题。1.1.0 引入了桌面分析流程、自动拆分通道和最终区域归档；科学规则仍为 1.0.1。

[阅读安装指南](../guide/)，了解系统要求和安装步骤。
