## 安装分析模块

打开 Project Leap 的**功能与维护**，选择所需模块。软件会一并下载模块及其依赖，包括分析运行环境、模型，以及需要时使用的 Fiji。

| 模块 | 当前版本 | 安装方式 |
| --- | --- | --- |
| 星形胶质细胞荧光强度分析 | v1.1.1 | 在 Project Leap 内安装 |
| 细胞计数 | v1.0.0 | 在 Project Leap 内安装 |

首次启动和模块设置见[安装指南](../guide/)。各版本的变化可查阅[荧光模块更新记录](https://github.com/DingchengWang/Project-Leap-2D-Integrated-IHC-fluorescence-analysis/blob/main/CHANGELOG.md)与[细胞计数发布记录](https://github.com/DingchengWang/Project-Leap-Cell-Counting/releases)。
